# Setup and troubleshooting

- **Installing optional dependencies:** create a virtual environment and run `python -m pip install -e '.[test,app]'`, and optionally `python -m pip install -e '.[aif360]'`. The RAND sample loads locally from statsmodels; it does not require HTTP at audit time.
- **`ModuleNotFoundError: fairlearn`:** independent count metrics and charts are generated by the package's own contingency-count engine. Official Fairlearn calls (MetricFrame, DP/EO differences) run only when `fairlearn` is installed, which the `.[test,app]` extra provides; after installing, run `pytest tests/integration/test_optional_libraries.py -q` and the full audit again.
- **`ModuleNotFoundError: aif360`:** same approach; AIF360 is an optional extra. Package transitive compiled dependencies may require Python 3.11/3.12. Metrics are shown only if AIF360 imports and evaluates.
- **`ModuleNotFoundError: streamlit`:** install `.[app]` before `python -m streamlit run app/streamlit_app.py`, and confirm the dashboard launches before treating it as working.
- **Undefined metric:** output JSON `null` means undefined (zero required class count / ratio denominator). Never substitute 0. Inspect stored TP, TN, FP, FN by group. `group_rows` excludes no observed group.
- **Invalid fractional `physlm` codes:** they are present in the packaged data and tracked as `2_other_code`; this is deliberate, not a normalization bug. Do not recode until original variable documentation supports it.
- **Reproducibility drift:** check `run.json` software versions, random seed, exact input hash, validation/heldout sizes, model params and dataset package version. Splits depend on floating-point coding of original source features. Other platforms/versions may differ slightly.
- **`joblib` safety:** serialized models are Python pickle-family objects; only load those you created from a trusted source.
- **Duplicated observations:** exact-profile grouping avoids known identical recorded feature profiles crossing folds. It is not a subject identifier and does not validate independence.
- **Report regeneration:** `python scripts/generate_report.py` renders the saved `run.json` and does not itself compute AIF360 metrics. `python scripts/run_audit.py` refits models and overwrites `results/latest` unless `--output` is specified.
